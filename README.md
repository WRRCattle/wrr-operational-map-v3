# WRR / ALR Operational Map — Standalone Safety Copy

This is version 3 of the third, independently published map requested on 18 August 2026. It is derived from the original WRR / ALR operational map at source commit `62ccf97ab6ba4a2203eba65c85c6bb284b332a6b` and does not modify the original repository or URL.

All overlay toggles now load off by default. The satellite basemap remains visible so the map does not open blank.

## Included Updates

- Rock Creek and Badger Creek watershed zones and LiDAR coverage.
- Full current 17 August 2026 WFIGS Grasshopper Fire perimeter.
- Terrain exposure across the current burned operational-watershed intersection.
- Watershed slope classes on an approximately 3-foot display grid, with the native-source limitation stated in the map.
- Four separate 10-acre channel-network toggles for Gate Creek, Rock Creek, 3 Mile Creek, and Badger Creek; all load off by default.
- Removal of the lower-left “The property” summary card.

The 1,617 derived channel segments are classified by the downstream endpoint of each segment within the four documented component catchments. Segment counts are Gate Creek 200, Rock Creek 316, 3 Mile Creek 224, and Badger Creek 877.
